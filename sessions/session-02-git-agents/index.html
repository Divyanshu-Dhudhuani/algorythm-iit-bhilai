Part 1 · branches — the idea that makes teams possible

main stays safe. You play on a branch.

$ experiment without fear
git branch redesign
git checkout redesign # or: git checkout -b redesign
●──●──● main (safe, deployable)
      ╰──●──● redesign (your playground)
git checkout main → git merge redesign
  • A branch is just a movable label on a commit.
  • Rule: never demo-broken code on main.
  • Merge = join your playground back into main.

READ THE DIFF LIKE THIS

- removed · + added

Red lines left your file, green lines entered. If the diff surprises you, don't add yet. diff is your pre-commit review.

Part 1 · undo — three levels of "oops"

Undo small. Rarely nuke.

SOFT UNDO

git restore file

Discard edits in one file. File goes back to last commit. Safe.

UNSTAGE

git reset file

Un-add a file. Edits stay, staging undone. Very safe.

☠ NUKE

git reset --hard

Erase ALL uncommitted work. No undo. Demo it once, fear it forever.

Golden rule: --hard destroys work permanently. Commit first (git commit -m "wip"), then experiment — you can always come back.
Restore = discard edits · Reset = unstage · --hard = erase10 / 23
Part 1 · how the open-source world collaborates

You never push to their repo. You PR it.

1

Fork

2

Clone + branch

3

Push + PR

push branch, click "Compare & pull request". Describe why.

4

Merge

Maintainer reviews, approves, merges. Your commit lands upstream.

Homework repos, GSoC, internships — every contribution you will ever make follows these 4 steps.

Live · we will break one on purpose

Conflicts aren't errors. They're Git asking you.

# Git marks the fight — you pick the winner
<<<<<<< HEAD
background: navy; # yours
=======
background: teal; # theirs
>>>>>>> redesign
$ then: edit → git add → git commit
  • Why: same lines changed in two places. Git can't guess — so it asks.
  • Fix: open the file, delete markers, keep what looks right.
  • Finish: add + commit. Conflict resolved, history clean.

Live · free key in 2 minutes

# never commit secrets

cat .gitignore # confirm .env listed
git status # .env must NOT appear
