Lost in terminal? Three commands fix that.

WHERE AM I?

pwd

Prints your current folder's full path. Run it whenever you feel lost.

WHAT'S HERE?

Lists files in this folder. ls -a also shows hidden ones like .git.

Part 1 · undo — three levels of "oops"

Undo small. Rarely nuke.

SOFT UNDO

git restore file

Discard edits in one file. File goes back to last commit. Safe.

UNSTAGE

git reset file

Un-add a file. Edits stay, staging undone. Very safe.

☠ NUKE

git reset --hard

Erase ALL uncommitted work. No undo. Demo it once, fear it forever.

Golden rule: --hard destroys work permanently. Commit first (git commit -m "wip"), then experiment — you can always come back.
Restore = discard edits · Reset = unstage · --hard = erase11 / 37

Concept · the line everyone pastes but nobody explains

remote is an address book. origin is a nickname.

$ nicknames for URLs — each line below is ONE command
git remote -v # list: must show fetch + push
git remote add origin https://github.com/<username>/<reponame>.git # save once
git remote set-url origin https://github.com/<username>/<reponame>.git # fix URL
git remote rename origin myfork # rarely needed
git remote remove origin # unlink only, files stay
  • origin = default nickname for your GitHub repo. Not magic, just a shortcut.
  • upstream = what your branch tracks: main → origin/main. Set once with push -u.
  • -u = --set-upstream. After that, bare push / pull know where to go.

Speaker: run git remote -v live — empty = you skipped Path A/B. set-url fixes a pasted wrong URL without re-adding.

Branches: one idea, six commands.

$ local vs tracked
git branch # list local, * = current
git branch -a # + remote-tracking: origin/main

  • Lost? git branch --show-current tells you where you are.
